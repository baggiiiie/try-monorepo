PROJECT OVERVIEW
================

tweet2blog is a CLI tool that converts X/Twitter threads into beautiful,
responsive blog-style HTML files with zero external dependencies.

KEY FEATURES
============
✅ Convert any Twitter/X thread URL to HTML/Markdown/JSON
✅ Standalone single-file output (embedded CSS/JS)
✅ Dark/light mode support
✅ Mobile responsive design
✅ Multiple fallback strategies (API → HTML scraping)
✅ Zero external dependencies
✅ Production-ready Go code
✅ Comprehensive documentation

HOW TO BUILD
============

1. Ensure Go 1.25+ is installed
2. Navigate to project directory
3. Run: make build
4. Binary is at: ./tweet2blog

HOW TO USE
==========

Basic:
  ./tweet2blog https://x.com/username/status/1234567890

Save to file:
  ./tweet2blog -o output.html https://x.com/username/status/1234567890

Markdown:
  ./tweet2blog --md https://x.com/username/status/1234567890

Verbose:
  ./tweet2blog -v https://x.com/username/status/1234567890

Help:
  ./tweet2blog --help

ARCHITECTURE
============

Data Flow:
  URL → Parser → Fetcher (API/HTML) → Builder → Renderer → Output

Key Components:
  - TwitterFetcher: Multi-strategy thread acquisition
  - GuestClient: X API v2 communication
  - Renderer: HTML/Markdown/JSON output
  - Logger: Structured logging

Design Goals:
  - Single binary, no dependencies
  - Clean separation of concerns
  - Fallback mechanisms
  - Production-grade code quality
  - User-friendly CLI
