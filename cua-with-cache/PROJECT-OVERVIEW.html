Native GUI · gui-cache

AX descriptor + operation

Pi selects one bounded current-UI candidate. The library compiles stable role, scope, ordinal, tokens, method, and delivery metadata—never generated JavaScript.

{ descriptor: { role: "AXCell", scope: "Message List", ordinal: 2 },  method: "click", addressing: "pixel" }

Cache miss invokes pi to resolve

1

Build key

Instruction, operation kind, app, route, schema, or variable names.

2

Lookup artifact

Read workflow, action, or extraction JSON by stable SHA-256 key.

3

Fresh UI

Read bounded AX structure; include a screenshot when compiling or pixel-addressing.

4

Ask Pi

Select an offered target or compile a bounded recipe. Validate the result.

5

Resolve + dispatch

Use a fresh token/frame. Dispatch once; acceptance alone does not prove the UI outcome.

6

Apply commit policy

Actions cache after acceptance, recipes after compilation and an application attempt, plans after output validation.

MISS

Pi compiles the missing artifact. Persistence then follows that artifact’s commit policy.

Cache

Key → value

Semantic request → replayable artifact

  • Cached: actions
  • Key: sha256({ instruction, app, operationKind, schema | variableNames })
  • Action value: versioned JSON with a durable AX descriptor and supported replay method
  • Not cached: screenshots, live content, element handles, process/window IDs, or absolute coordinates
.gui-cache/outlook/actions/<sha256>.json

JSON → replay
1 · LoadHash the request and read the matching action JSON.
2 · ResolveMatch its descriptor against a fresh AX snapshot.
3 · BindUse the fresh element handle—or derive a point from its current frame.
4 · DispatchCall the cached method once. If resolution is stale, ask Pi to replace the entry instead.

Why not Simulang?

PRESERVE
  • No background mouse clicks
  • DFS revisits duplicate or cyclic Outlook AX nodes.
  • maxNodes can run out before reaching Message List.
  • scoredSearch can return hundreds of duplicate-looking global-best matches.
  • Full app-root traversal is expensive; one probe was killed before returning.

Future Improvements

01

Coordinate → durable AX identity

Hit-test a Pi-selected visual point back to an AX element. Cache it only when the element has durable identity and matches the visual target.

02

One backend-independent element.click()

Resolve fresh, prefer semantic AX action, otherwise click a validated point in the current frame.

  • Do not assume AX press and coordinate click are equivalent.
  • Account for focus, pointer movement, occlusion, scaling, and conversion.
  • Never fall back after an uncertain AX dispatch.
  • Use workflow risk and postconditions to decide whether fallback is safe.
03

Bounded see()

Return a compact AX view when small, or a screenshot when structure is huge. Prefer keyword-scoped AX search over asking a model to inspect an unbounded tree.

04

Harden Simulang traversal

Use breadth-first search or a DFS-to-BFS fallback, deduplicate candidates, and surface node-budget exhaustion.

05

Cross-scope data flow

Bind named live extraction outputs from one app into later actions in another app without persisting those values in workflow or action caches.
