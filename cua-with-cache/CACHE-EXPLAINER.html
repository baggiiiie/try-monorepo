02 / Cache outcomes

The report tells you which path ran

HIT

Compiled action re-resolved and replayed. No model.

MISS

Pi resolved the instruction and the validated action was stored.

HEALED

A stale replay step was recompiled and its cache entry replaced.

REFUSED

Ambiguous, unsafe, invalid, drifted, or failed verification. No speculative action.

03 / Self-healing

Pi is a bounded action resolver

Only misses and stale steps use Pi. It chooses from the current GUI; the library validates and compiles the replay artifact.

A
Prepare

Build safe context

Capture bounded AX structure plus the current screenshot. Ephemeral handles may identify offered candidates but never become cache identity.

B
Select

One Pi model turn

Pi selects one offered target and a supported method. It cannot run arbitrary tools or edit workflow source.

C
Validate

Compile and fail closed

Check candidate, method, confidence, scope, replay identity, and live stability. Persist the compiled action—not model prose or ephemeral handles.

04 / Safety boundaries

What healing deliberately does not do

No source generation

Structured actions, not code

Pi selects a bounded target and method. It does not edit scripts, invoke a coding agent, or run Pi's TUI.

No retry

No healing after dispatch

If an action may have happened, failure remains visible. Postcondition failure never causes a second click or model repair.

No semantics

No cached app data

extract reads a bounded live NodeView through deterministic caller projections. Outlook meaning stays under examples/.
