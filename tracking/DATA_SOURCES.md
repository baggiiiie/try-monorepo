# Data Sources

## Apple Ecosystem
- **Calendar**: EventKit for reading/writing events.
- **Health**: HealthKit for sleep, HR, HRV, workouts, mindfulness.
- **Location**: CoreLocation for significant changes and geofences.
- **Motion**: CoreMotion for steps, flights climbed, activity states.
- **Music**: MusicKit for recently played (Apple Music subscribers).
- **Screen Time**: DeviceActivity/FamilyControls allow app usage insights but not full system history.

## External Services
- **Spotify**: Web API for recently played and playback state.

## Not Accessible on iOS
- Safari history, email content, and full device-wide app usage logs.
